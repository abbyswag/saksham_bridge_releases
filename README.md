# Saksham Bridge — installers

This repository only hosts release installers for the Saksham Bridge desktop
companion app. Source code lives in the private `saksham_bridge` repository.

Download the latest:
- macOS: `saksham-bridge-macos.dmg`
- Windows: `saksham-bridge-windows.msi`
- Windows fallback: `saksham-bridge-windows-setup.exe`

Go to the **Releases** tab on the right.
